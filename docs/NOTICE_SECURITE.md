# Avis de sécurité / scope phase 1

- Prototype pour PC exclusivement, données **100 % simulées**.
- Ce programme n'est **pas un instrument de sécurité routière**, un outil de diagnostic agréé ni un combiné homologué.
- Ne jamais remplacer, recouvrir, retirer ou débrancher le combiné Renault d'origine avec cette application.
- Les compteurs et voyants présentés **ne reflètent pas l'état réel du véhicule**.
- Les valeurs de vitesse, température, carburant, pression d'huile, freinage, ABS, airbag et kilométrage sont fictives.
- Un état « inconnu » n'est jamais présumé « sûr » ; en particulier un voyant non allumé dans cette application ne garantit aucune sécurité.
- Les données peuvent varier de manière non réaliste : la simulation privilégie la couverture des états visuels et les tests automatisés.
- Le modèle logiciel ne possède aucune primitive d'émission CAN, d'écriture OBD-II ni de commande des calculateurs.
- Avant une éventuelle utilisation embarquée, prévoir tests sur écran supplémentaire hors du champ des instruments d'origine, reprise électrique sécurisée et étude réglementaire préalable.
